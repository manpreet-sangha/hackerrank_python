# HackerRank Python Solutions

A collection of Python solutions for HackerRank coding challenges.

## Problems

| File | Problem | Description |
|------|---------|-------------|
| `averageScores.py` | Finding the Percentage | Compute average marks for a queried student |
| `commandInputs.py` | Lists | Perform list operations based on user commands |
| `conditionalPython.py` | If-Else | Practice conditional statements |
| `countingValleys.py` | Counting Valleys | Count valleys traversed during a hike |
| `execute_command.py` | Execute Command | Execute system commands from Python |
| `findAngleMBC.py` | Find Angle MBC | Find the angle MBC in a right triangle |
| `hourglass.py` | 2D Array - DS | Find the maximum hourglass sum in a 6x6 2D array |
| `jumpingOnClouds.py` | Jumping on the Clouds | Find minimum jumps to reach the last cloud |
| `leapYear.py` | Leap Year | Determine if a year is a leap year |
| `linear_algebra.py` | Linear Algebra | Solve linear algebra problems using NumPy |
| `listComprehension.py` | List Comprehensions | Generate lists using comprehensions |
| `pairsOfSocks.py` | Sales by Match | Count pairs of matching socks |
| `palindrome.py` | Palindrome | Check if a string is a palindrome |
| `pangram.py` | Pangrams | Check if a string contains all letters of the alphabet |
| `polar_coordinates.py` | Polar Coordinates | Convert complex numbers to polar coordinates |
| `print_HackerRank.py` | Print HackerRank | Print "HackerRank" pattern |
| `printN-1numbers.py` | Print N-1 Numbers | Print first N-1 numbers |
| `printNumbers.py` | Print Numbers | Print a sequence of numbers |
| `queueBribe.py` | New Year Chaos | Determine minimum bribes in a queue |
| `runnerupScore.py` | Runner-Up Score | Find the second highest score |
| `secondLowestScore.py` | Nested Lists | Find students with the second lowest grade |
| `split_string.py` | Split String | Split and manipulate strings |
| `threatDetector.py` | Threat Detector | Analyze and detect security threats |
| `welcomeMat.py` | Welcome Mat | Print a welcome mat pattern |

## How to Run

`bash
python <filename>.py
